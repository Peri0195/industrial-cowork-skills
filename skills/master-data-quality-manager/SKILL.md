# 物料主数据缺项与重复检查

## 何时使用
检查物料编码重复、必填字段缺失及单位是否在指定词表中。

## 输入与前置检查
输入为UTF-8 JSON对象，字段结构见[输入契约](references/data-contract.md)及[完整样例](examples/input.json)。按用户原始记录建立输入，不编造缺失数据。所有时间、数量、货币和距离须在同一统计口径下。
运行依赖Python 3.10及以上，仅标准库；无需密钥、联网服务或商业软件。先确认Python可用；不可用时说明阻塞，不输出伪计算结果。

## 工作流
1. 确认用户任务在本包执行范围内。读取输入契约；缺必填字段时先补齐。
2. 将输入JSON保存到当前任务目录，保留用户原始值。使用技能目录下的`scripts/run.py`执行。
3. 调用方式：`python <技能目录>/scripts/run.py --input <任务目录>/input.json --out <任务目录>/result`。路径有空格时加引号；以实际技能目录替换尖括号内容。
4. 退出码2表示输入无效；读取错误信息并说明需修正字段，不以零替代缺失值。退出码0后读取`result/report.json`，核查关键结果，再向用户解释。
5. 交付`report.json`和`report.md`，说明输入单位、计算范围和未覆盖项。数字必须来自脚本输出；文件未生成时不得报告成功。

## 方法与输出
逐行检查；重复编码列出编码值，缺项按行号和字段输出，单位词表由用户提供。

`report.json`含结构化结果，`report.md`保留同一结果的可读副本。输出字段及样例预期见[验收样例](examples/expected.json)。样例不是用户数据，只有验收请求才使用它。

## 适用边界
不自动修改主数据，不校验物料技术参数或ERP编码规则。
脚本不会写入ERP、修改设备参数、发出采购订单或对外发送消息。输出是离线计算或检查结果。
