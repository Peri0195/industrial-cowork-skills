# 设备综合效率计算与损失核对

## 使用范围
处理用户提供的离线生产统计。输出OEE、时间开动率、性能率、质量率及异常输入说明。不连接、不控制生产设备。不把OEE低直接解释为故障或某个根因。

## 工作流程
1. 读取用户数据，按 references/data-contract.md 确认统计边界、单位和缺失项。五个必填值缺少时先补齐，不猜测。
2. 把数据保存为JSON。定位本技能目录，用可用Python运行 scripts/calculate_oee.py。脚本只依赖Python标准库。
3. 如果返回码为2，将错误与需复核的原始字段告诉用户，修正后再计算。不得为通过计算而随意改变产量或节拍。
4. 读取report.json，展示三项分率、OEE、停机时间和不良数量；说明计算口径。数字必须来自脚本结果。
5. 如需六大损失、TEEP或趋势分析，完整方法说明见 references/original-skill.md；这些扩展并未由本计算入口实现，应根据用户补充数据另行分析，不能伪称本脚本已产出。

## 快速调用
从本技能目录运行：
```sh
python scripts/calculate_oee.py --input examples/input.json --out result
```
生产数据请替换为用户提供的JSON路径，输出写入当前任务目录，不覆盖参考样例。

## 验收样例
样例：计划480分钟、运行432分钟、节拍0.4分钟、总产864件、良品821件。
应输出开动率90%、性能率80%、质量率95.023148%、OEE68.416667%。
结果容差为0.000001个百分点。错误输入必须报错，不自动截断。
